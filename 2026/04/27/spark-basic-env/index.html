Spark 基础环境配置

一、实验目的

掌握 Spark 基础运行环境的搭建，熟练完成 JDK、Hadoop、Spark 的安装与配置，能够正常启动 Spark 环境。

二、实验环境

  • JDK 1.8
  • Hadoop 3.3.x
  • Spark 3.3.x
  • Linux 系统

三、实验步骤

  1. 安装并配置 JDK，配置 JAVA_HOME 环境变量。
  2. 安装 Hadoop，配置 HADOOP_HOME 及相关配置文件。
  3. 解压 Spark，配置 spark-env.sh 文件，指定 JAVA_HOME 与 HADOOP_CONF_DIR。
  4. 配置 Spark 环境变量，使 spark-shell、spark-submit 可全局调用。

四、实验验证

执行 spark-shell 命令，正常进入 Spark 交互界面即表示环境配置成功。
