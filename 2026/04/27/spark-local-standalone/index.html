Spark Local 与 Standalone 模式

一、实验目的

理解 Spark 的 Local 本地模式与 Standalone 集群模式，掌握两种模式的启动与任务提交方法。

二、Local 模式

Local 模式用于本地测试，不需要集群，直接在单节点运行。
启动命令：
spark-shell –master local[*]

三、Standalone 模式

  1. 配置主节点与从节点，修改 slaves 文件。
  2. 启动 Master：start-master.sh
  3. 启动 Worker：start-slaves.sh
  4. Web UI 访问地址：http://localhost:8080

四、提交任务

spark-submit –master spark://master:7077 实例程序
