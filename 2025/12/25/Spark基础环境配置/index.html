Spark 基础环境配置

一、实验目的

掌握 Spark 运行环境的基础搭建流程，理解 Spark 依赖的基础组件。

二、环境准备

  1. JDK 1.8 及以上
  2. Hadoop 环境（可选）
  3. Scala 环境
  4. Spark 安装包

三、安装步骤

1. JDK 安装与配置

  • 配置 JAVA_HOME
  • 配置 PATH 环境变量
  • 验证：java -version

2. Scala 安装

  • 解压并配置 SCALA_HOME
  • 验证：scala -version

3. Spark 解压与配置

  • 解压 spark 安装包
  • 配置 SPARK_HOME
  • 修改 spark-env.sh 文件

4. 启动 Spark

  • 执行 start-all.sh
  • 访问 Web UI：http://localhost:8080

四、实验总结

成功完成 Spark 基础环境搭建，能够正常启动 Spark 服务并访问管理界面。
